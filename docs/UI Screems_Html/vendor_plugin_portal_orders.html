Listing Standards
What every fulfilment type must include before a product can be published. Your plugin enforces these automatically.
ℹ️ These are the baseline requirements across every product category on the marketplace. Step 3 (Content & Media) of the product wizard only shows the fields relevant to the fulfilment type you picked — this page is the full reference.
📷 Ecommerce & physical products — SHIP_PHYSICAL
Primary image1:1 square, min 1000×1000px, JPG/PNG/WebP, max 5MB, plain/white background
Gallery imagesUp to 8 additional, same size standard, lifestyle + detail shots recommended
VariantsSize / colour / material options with per-variant stock
LogisticsSKU, weight, package dimensions, ships-from pincode
🎓 LMS & education / courses — STREAM_LMS_COURSE
Course thumbnail16:9, min 1280×720px, JPG/PNG/WebP, max 5MB
Intro / promo videoHosted URL (YouTube/Vimeo/CDN), 1–5 min recommended
CurriculumLesson-by-lesson list, each with title, video URL, duration
Study materialDownloadable PDFs/slides/worksheets per course or per lesson
MetadataSkill level, language, total duration, certificate on/off, instructor bio
💾 Digital products — DELIVER_DIGITAL
Preview image1:1 square, min 1000×1000px
Deliverable file(s)The actual file(s) buyers receive — PDF, ZIP, font, template, etc.
LicensingPersonal / commercial / extended use terms stated clearly
💻 Software products — LICENSE_SOFTWARE
Icon / screenshotApp icon (square) + at least 2 product screenshots
CompatibilityOS / platform support, minimum system requirements
DeliveryInstaller/download URL, version number, license key mechanism
☁️ Software & SaaS services — PROVISION_SOFTWARE
Product logoSquare icon, min 512×512px
Plan tiersWhat's included at each plan level, seat/usage limits
OnboardingWhat happens immediately after a tenant installs (account/workspace setup)
☁️ Cloud & infrastructure services — PROVISION_CLOUD
Service iconSquare icon, min 512×512px
Technical specsAvailable regions, compute/storage specs, API endpoint docs
SLAUptime commitment, data residency, support response times
🎬 Multimedia & streaming services — DELIVER_MULTIMEDIA
Cover art / thumbnail1:1 or 16:9 depending on media type, min 1280px on the long edge
Sample / previewShort preview clip URL for buyers to evaluate before purchase
Format & rightsResolution/bitrate options, DRM status, usage rights/runtime
🔧 Professional & field services — DISPATCH_SERVICE
Provider photoHeadshot or team photo, square, min 500×500px
CoverageService area / radius, response time SLA
📅 Appointments & sessions — BOOK_APPOINTMENT
Profile photoSquare, min 500×500px
Session detailsDuration, format (video/in-person), calendar availability
