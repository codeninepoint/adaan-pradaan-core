👤 User Account
A human-operated account. Signs in via email+password or OAuth. Subject to MFA, session limits, and email verification.
PropertyValue
Auth MethodEmail/Password, Google OAuth, OTP
MFAOptional (mandatory for Admins)
Session TTL8 hours (configurable per role)
Email VerificationRequired before first login
ProfileName, avatar, phone, address
Can Hold RoleCustomer → Vendor Admin → Tenant Admin
First User CreatedAuto-assigned Platform Admin
🔑 Service Account
A non-human identity for integrations, plugins, bots, scheduled jobs. No password login — uses API keys + HMAC signing only.
PropertyValue
Auth MethodAPI Key + HMAC-SHA256 signature
MFANot applicable
Session TTLAPI key rotation cycle (30/90 days)
Key CountUp to 5 active keys per account
ScopeScoped to specific plugin or integration
Can Hold RoleLimited: read-only or scoped write
Created ByTenant Admin or Platform Admin only
